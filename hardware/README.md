For buyer before 20250626:  
We are very sorry. Due to the problem with the document provided by WCH, ISP download via USB is very likely to fail (the reason is that a resistor in the USB enumeration circuit has the wrong value). The product shipped after 20250626 have been fixed. Customers purchased before this need to make the following changes:
Change the R1 resistor from 5.1K to 1.5K (the footprint is 0402)
